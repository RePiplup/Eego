# Eego 鹅鹅下载

Eego 是一款界面简洁的 Windows 下载工具。粘贴链接就能新建任务，在同一个窗口查看进度、暂停或继续下载。支持普通下载链接、磁力链接和本地种子文件。

**[下载 Windows 64 位最新版](https://github.com/RePiplup/Eego/releases/latest)** · v0.10.0 安装包约 149 MiB。在发布页的 **Assets** 中选择以 `windows-x64-setup.exe` 结尾的文件。

**装好后有多大？** 同一台 Windows 电脑上，Eego 0.10.0 的安装目录约 227 MiB，迅雷 25.1.40.1703 约 1.30 GiB。按两个安装目录内全部文件的大小合计，Eego 约为迅雷的 **17%（约六分之一）**。实际大小会随版本和使用情况变化。

## 开始下载

1. 运行安装包，从开始菜单打开 **Eego**。
2. 点击 **新建任务**，粘贴 HTTP、HTTPS 或磁力链接。多个链接可以每行放一个。已有种子文件可点 **打开本地种子…**。
3. 选择保存目录并提交任务。磁力链接读取到文件清单后，可以勾选想下载的文件。

## 用 Edge 或 Chrome 接管下载（可选）

安装或升级 Eego 时，安装程序会为当前用户注册 Edge 和 Chrome 的通信程序。使用 0.10.4 或更早的安装包时，请先从开始菜单运行一次 **Eego → Browser Setup**。

首次加载助手时，在浏览器的扩展管理页开启「开发者模式」，点击「加载解压缩的扩展」，选择安装目录中的 `browser/extension` 文件夹。曾从开发目录加载助手的用户也请在此选择安装目录。打开「Eego 下载助手」，勾选「尝试接管下载」。

**更新版本**　从 0.10.2 起，Eego 启动时会检查正式版。看到提示后点「下载并安装」，软件会下载安装包、校验文件、保存任务并在原目录覆盖升级。也可以从「设置 → 检查更新」手动重试。0.10.0 用户需要先手动安装一次新版。手动升级时请退出 Eego，沿用原安装目录以保留历史记录。
