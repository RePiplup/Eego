# 按需显示网站授权提示（2026-10-29，0.8.6）

修复旧面板把每次请求的网站保存为 sessionSite、始终展示为“登录下载网站”的问题。普通请求不再产生授权候选；弹窗默认隐藏整个授权区，打开时丢弃旧 sessionSite，但保留已授予的权限。

HTTP 内核用 BrowserAuthorizationError 区分同源 401/403、下载重定向至 /login 或 /signin HTML 页面；GUI 将当前进程中这类失败通过原生状态 5 返回。普通 404、HTML 网页、网络错误与跨源 401/403 不触发原网站授权提示。401/403 也可能是访问权限问题，因此提示说明“被拒绝或转到登录页”，不宣称已确定需要 Cookie 授权。

扩展在当前下载发生上述失败后检查该网站的 cookies 与 origin 权限，未授权才显示对应网站。已授权、隐私窗口、普通下载、输入框切换其他网站时隐藏。新下载替换旧上下文，旧异步结果不能覆盖新提示；提示仅保存在浏览器 session storage，两分钟过期，关闭浏览器即失效；授权完成、拒绝或点击“暂不授权”均清除该提示。Cookie 权限依旧只能通过用户点击申请，没有增加 manifest 权限。

手动发送任务也在后台检查结果；自动接管在浏览器已完成时仍可检查原生下载失败，避免遗漏授权候选。监测仍以原有约 60 秒窗口为限，排队或耗时超过该窗口的失败应在任务窗口查看；登录页识别采用保守路径规则，不覆盖所有站点登录形式。已有 POST、分区 Cookie、跨源会话限制不变。
