# 浏览器历史下载误接管修复（2026-10-29）

扩展版本 0.8.5，GUI 仍为 0.8.4。本次没有更换下载内核。

旧实现收到 onCreated 后立即创建原生任务，之后才判断浏览器任务是否已完成，缺少开始时间与重复事件防护。

现在仅自动接管开始不超过 15 秒、正在传输且未暂停的安全 HTTP(S) 下载。缺失/无效/未来时间、完成、已中断、历史恢复条目均跳过。开启接管时记录时间，排除开启前的下载。查询浏览器当前状态后才登记接管；读取登录信息后、发送原生消息前再次核对状态和开关。

以浏览器 ID 与开始时间组合进行持久化去重，串行登记但不串行等待下载。登记发生在原生消息前，即使主机失联或工作线程重启也不会自动重复提交；用户可以从右键或扩展输入框手动重新发送。登记仅存编号与时间，最多保留 2048 条、24 小时；时间过滤阻止更早事件再次进入。非常短的下载若已在浏览器完成，或事件延迟超过 15 秒，会保留在浏览器而不自动接管。
