# HandmadeBT 0.5 最小 Windows 下载界面

## 打开与使用

解压整个包，双击根目录 **HandmadeBT.cmd**。也可直接打开 **bin/handmadebt.exe**，二者使用同一份包根目录 `userdata`。不要在 ZIP 内直接运行。界面不需要 Python、编译器或管理员权限；包内 Python 只服务于测试。

1. 在上方粘贴一条或多条 HTTP/HTTPS 链接，每行一条。
2. 确认保存目录，点“添加下载”。本版按队列顺序下载，每个任务有独立文件名前缀，避免同名覆盖。
3. 选中任务，点“暂停选中”或“恢复 / 重试”。关闭窗口会请求暂停、保存列表，等待当前网络调用返回后退出；重开后任务保留，点击恢复继续。
4. 完成状态只在重新读取磁盘内容校验通过后出现。选择任务可看完整路径、真实错误和实际 SHA-256。

可选校验格式：`URL | 64 位 SHA-256`。有来源提供的哈希时会同时验证它；未提供时比较“收到的字节摘要”和“磁盘读回摘要”，界面明确写“写入校验通过”，不冒充已验证远端发布者身份。

“实际接收进度”来自内核读网络、写盘和恢复时重验的字节计数。预分配文件长度不参与进度或成功判定。接收进度 100% 仍可能因校验失败显示“错误”；只有“已完成”才代表该任务的内容校验通过。

## 独立界面验收

双击根目录 **GUI-Isolated-Test.cmd**。它生成一个全新的 `test-output/界面 验收 …` 目录、8 MiB 测试文件、已知哈希和真实本地 HTTP 服务，并打开使用独立任务目录的界面，不碰正式 `userdata`。

- `single-link.txt`：慢速下载及暂停恢复；复制其中内容到窗口。
- `batch-links.txt`：多行下载、404、未受信任 TLS 和错误哈希；后三者应该失败。
- `links.txt`：还包含不支持 Range 的服务，供检查安全回退。
- `expected.bin` / `fixture.json`：自产原文件、预期 SHA-256、端口和隔离路径。
- `README-test.txt`：逐步验收说明。

测试服务控制台输入 `f` 加速、`s` 慢速、`r` 重开同一隔离任务界面、`v` 独立逐文件核验、`q` 停服务。先关闭隔离界面再输入 `r`，避免同一列表重复打开。服务停掉后，对应的本地链接会报连接错误，这是预期行为。不要安装测试证书或关闭证书检查。

自动底层回归仍用 `run-selftest.cmd`，包括 20 项在线下载和 30 项恢复/文件保护检查；**它不冒充点击界面测试**。

## 实现及验收边界

- `src/gui.cpp`：原生 Win32 界面、单活动任务队列、任务列表原子保存和重开、独占列表锁。
- `src/http.{hpp,cpp}`：新增可选 `HttpControl`，按钮设置真正的取消请求，接收循环响应并保存已完成块；传入原有 CLI 的预设暂停参数始终为 0。暂停可能等待 WinHTTP 当前调用的超时，不承诺毫秒级即时中断。
- GUI 直接静态链接 `download_core`。不启动 aria2c、RPC、core_cli 或独立下载引擎进程；Python 测试服务器不承担下载内核工作。
- Range 服务继续使用两块合并保存、强 ETag、已有文件归属和恢复校验。不支持 Range 时 GUI 自动单连接下载；暂停后安全从零重下，不能伪装为断点续传。CLI 原有“不支持分段则明确拒绝”的行为保留。
- 完成前分块重读并与收到的摘要比较，再计算整文件 SHA-256；提供期望值时额外比较。重开列表时重验已完成文件，缺失或内容改变会显示错误而不覆盖原文件。
- 任务列表 `userdata/tasks.record` 有校验和及原子替换；损坏时明确拒绝打开，不清空原列表。`.resume` / `.part` 保持原保护。列表锁防止同一数据目录的两个界面同时运行。

本轮真实窗口验收记录在工作区 `docs/GUI_ACCEPTANCE.md`（最终包验收后写入），包括实际按钮操作、关闭重开、单条/多行、HTTP/HTTPS、404、TLS 拒绝、错误哈希、不分段回退。所有成功文件另行 SHA-256 核验。工具曾受窗口切换和网络沙箱影响；失败不计作通过。

本版仍有明确范围：最多 500 条保留任务，单活动任务，无删除/排序/全局资源治理；暂不支持重定向、chunked、压缩或未知长度、零字节文件、一般认证/代理；BT 尚未接入界面。浏览器接管、HLS/DASH、其余 BT 能力继续保留为最终需求。本轮没有扩展它们，也没有宣称完成全新机器、断电或长期公网验收。

## 构建和来源

`./tools/build.ps1` 生成 `build/handmadebt.exe` 和原测试 CLI。固定上游、工具链见 `provenance/inputs.lock.json`；源码随包附于 `source.zip`，原始许可证、版权与来源记录保留。`provenance/package-inputs.json` 记录 GUI/CLI 的实际二进制 SHA-256；`manifest.json` 记录交付文件摘要。
